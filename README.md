# Telegram-бот на Python

Учебный проект по дисциплине «Интероперабельность приложений и систем».

# Описание проекта

Telegram-бот предназначен для демонстрации взаимодействия Python-приложения с Telegram Bot API и сторонними веб-сервисами.

# Возможности бота

- `/start` — запуск бота и отображение меню.
- **Мой ID** — получение Telegram ID пользователя.
- **Помощь** — информация о командах.
- **Фото котика** — получение случайной фотографии через TheCatAPI.
- **Возраст по имени** — примерное определение возраста через Agify API.
- **Отправить геолокацию** — получение погоды по координатам через Open-Meteo.
- **Аватар робота** — получение изображения через RoboHash.

# Структура проекта

- `main.py` — основной файл запуска и настройки логирования.
- `bot.py` — настройка и запуск Telegram-бота.
- `handlers.py` — обработчики команд и действий пользователя.
- `utils.py` — функции взаимодействия со сторонними API.
- `.env` — хранение токена бота.
- `requirements.txt` — список необходимых библиотек.
- `.gitignore` — список файлов, которые не должны попадать в Git.

# Используемые технологии

- Python
- python-telegram-bot
- httpx
- python-dotenv
- Telegram Bot API
- TheCatAPI
- Agify API
- Open-Meteo API
- RoboHash API

# Запуск проекта

1. Установить Python.
2. Установить зависимости:

   `pip install -r requirements.txt`

3. Создать файл `.env` и указать токен:

   `BOT_TOKEN=your_token`

4. Запустить бота:

   `python main.py`
